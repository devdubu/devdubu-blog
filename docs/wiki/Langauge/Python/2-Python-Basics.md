# Python 기초 문법

:::info 개요
**Python**의 핵심 특징인 들여쓰기와 기본 자료형(정수, 실수, 문자열), 그리고 변수 선언 규칙을 다룹니다.
:::

## 1. 파이썬의 특징

### 1.1 들여쓰기 (Indentation)
Java나 C와 달리 중괄호 `{}` 대신 **들여쓰기**로 코드 블록을 구분합니다.

```python
if True:
    print("True")  # 들여쓰기 필수
else:
    print("False")
```

### 1.2 세미콜론 생략
문장의 끝에 세미콜론(`;`)을 붙이지 않아도 됩니다. (붙여도 에러는 아니지만 권장하지 않음)

### 1.3 주석 (Comment)
```python
# 한 줄 주석

"""
여러 줄 주석 (Docstring)
쌍따옴표 3개 사용
"""
```

---

## 2. 변수 (Variables)

동적 타입 언어이므로 타입을 명시하지 않아도 됩니다.

```python
a = 100
b = "Hello"

# 다중 할당
x, y = 10, 20
```

### 네이밍 규칙
- 영문자, 숫자, 언더바(`_`) 조합.
- 숫자로 시작 불가.
- 대소문자 구분 (`MyVar` != `myVar`).
- 예약어 사용 불가 (if, class, def 등).

---

## 3. 자료형 (Data Types)

`type()` 함수로 변수의 타입을 확인할 수 있습니다.

### 3.1 숫자형 (Number)
```python
i = 10      # int (정수)
f = 3.14    # float (실수)
```

### 3.2 문자열 (String)
작은따옴표(`'`)나 큰따옴표(`"`)로 감싸서 표현합니다.

```python
s = "Python"
multiline = """
여러 줄에 걸쳐
문자열 작성 가능
"""
```
