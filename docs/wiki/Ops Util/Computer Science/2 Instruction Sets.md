# 고급 언어와 저급 언어

우리가 프로그램을 만들 때 사용하는 프로그래밍 언어(C, Java, Python 등)는 컴퓨터가 이해하는 언어가 아닌, 사람이 이해하고 작성하기 쉽게 만들어진 언어입니다. 이를 **고급 언어(High-Level Language)**라고 합니다.

반면, 컴퓨터가 직접 이해하고 실행할 수 있는 언어는 **저급 언어(Low-Level Language)**라고 합니다.

:::tip 고급 언어 vs 저급 언어
- **고급 언어**: 사람을 위한 언어 (가독성 높음, 하드웨어 추상화)
- **저급 언어**: 컴퓨터를 위한 언어 (기계어, 어셈블리어)
:::

## 기계어 (Machine Code)
컴퓨터는 0과 1로 이루어진 **기계어**만을 이해하고 실행합니다.
기계어는 0과 1의 나열로 되어 있어 사람이 이해하기 매우 어렵습니다. 이를 16진수로 표현하기도 하지만 여전히 난해합니다.

> 예: `10110000 01100001` (이진수) -> `B0 61` (16진수)

## 어셈블리어 (Assembly Language)
기계어는 사람이 읽기 힘들기 때문에, 이를 읽기 편한 형태로 1:1 대응하여 번역한 언어가 **어셈블리어**입니다.

:::note 어셈블리어
기계어 명령어를 `MOV`, `ADD`, `PUSH` 와 같은 니모닉(Mnemonic)으로 표현하여 가독성을 높인 저급 언어입니다.
:::

# 컴파일 언어와 인터프리터 언어

고급 언어로 작성된 소스 코드는 저급 언어로 변환되어야 실행될 수 있습니다. 이 변환 방식에 따라 크게 두 가지로 나뉩니다.

## 컴파일 언어 (Compiled Language)
- 소스 코드 전체를 한 번에 기계어(또는 중간 코드)로 변환(컴파일)한 후 실행합니다.
- **장점**: 실행 속도가 빠릅니다. (이미 변환되어 있으므로)
- **단점**: 코드를 수정하면 다시 컴파일해야 합니다.
- **예시**: C, C++, Go, Rust

## 인터프리터 언어 (Interpreted Language)
- 소스 코드를 한 줄씩 읽어가며 즉시 번역하고 실행합니다.
- **장점**: 코드 수정 후 즉시 실행 결과를 볼 수 있어 개발 속도가 빠릅니다.
- **단점**: 줄 단위로 번역하며 실행하므로 실행 속도가 컴파일 언어보다 느릴 수 있습니다.
- **예시**: Python, JavaScript, Ruby
