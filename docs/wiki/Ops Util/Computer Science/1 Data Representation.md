# 정보 단위

컴퓨터는 0과 1 밖에 이해하지 못합니다.
0과 1을 나타내는 가장 작은 정보 단위를 **bit**라고 합니다.

비트는 0, 1 두 가지 정보를 표현할 수 있습니다.
n개의 전구로 표현할 수 있는 상태는 $2^n$ 입니다.

하지만, 우리가 사용하는 모든 프로그램의 크기를 말할 때 이를 $2^n$으로 말하진 않습니다.
우리는 흔히 아래의 단위를 사용합니다.

| 단위 | 설명 | 크기 |
| --- | --- | --- |
| **Why?** | 비트 만으로는 표현하기 벅차기 때문 | |
| **Byte** | 8bit | 1 byte |
| **kB** | 1,000 byte | $10^3$ byte |
| **MB** | 1,000 kB | $10^6$ byte |
| **GB** | 1,000 MB | $10^9$ byte |
| **TB** | 1,000 GB | $10^{12}$ byte |

:::tip Word?
중요한 정보 단위 중 **워드(Word)**라는 단위도 있습니다.
- 워드란 CPU가 한 번에 처리할 수 있는 데이터 크기를 의미합니다.
- 만약 CPU가 한 번에 16비트를 처리할 수 있다면, 1워드는 16비트가 됩니다.
- 한 번에 32비트를 처리할 수 있다면 1워드는 32비트가 됩니다.
- 워드의 절반 크기를 **half word**, 1배 크기를 **full word**, 2배 크기를 **double word**라고 부릅니다.
- 워드 크기가 큰 CPU는 한 번에 처리할 수 있는 데이터가 많습니다.
- 현대 컴퓨터는 대부분 **64비트** 워드 크기를 가집니다.
:::

# 이진법

0과 1만으로 숫자를 표현하는 방법을 알아보겠습니다.

:::note 이진법이란?
수학에서 0과 1만으로 모든 숫자를 표현하는 방법을 **이진법(Binary)**이라고 합니다.
:::

이진법을 이용하면 1보다 큰 수도 0과 1만으로 표현할 수 있습니다.
숫자가 1을 넘어가는 시점에 자리 올림을 하면 됩니다.

# 문자 인코딩 (Character Encoding)

컴퓨터는 0과 1만 이해할 수 있으므로, 문자도 숫자로 변환하여 저장해야 합니다. 이를 **문자 인코딩**이라고 합니다.

## 아스키 코드 (ASCII)
- **ASCII(American Standard Code for Information Interchange)**는 초창기 문자 집합으로, 7비트를 사용하여 128개의 문자를 표현합니다.
- 영어 대소문자, 숫자, 일부 특수문자만 표현 가능하며, 한글 등 다른 언어는 표현할 수 없습니다.

## 유니코드 (Unicode)
- **유니코드**는 전 세계의 모든 문자를 컴퓨터에서 일관되게 표현하고 다루기 위해 만들어진 산업 표준입니다.
- **UTF-8**: 유니코드를 저장하는 인코딩 방식 중 하나로, 문자에 따라 1바이트에서 4바이트까지 사용하는 **가변 길이 인코딩** 방식을 사용합니다. 웹에서 가장 널리 사용되는 인코딩 방식입니다.
