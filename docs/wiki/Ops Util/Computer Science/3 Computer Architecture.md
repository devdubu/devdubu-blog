# 컴퓨터가 이해하는 정보
컴퓨터는 0과 1로 표현된 정보만 이해합니다. 정보에는 두 종류, **데이터**와 **명령어**가 존재합니다.

![Diagram12.svg](/img/Diagram12.svg)

:::info 데이터와 명령어
- **데이터(Data)**: 컴퓨터가 이해하는 숫자, 문자, 이미지, 동영상과 같은 정적인 정보입니다.
- **명령어(Instruction)**: 컴퓨터를 실질적으로 작동시키는 정보입니다. 데이터는 명령어 없이는 아무것도 할 수 없습니다.
:::

# 컴퓨터의 4가지 핵심 부품

![Pasted-image-20240804214321.png](/img/Pasted%20image%2020240804214321.png)

## 1. 메모리 (Main Memory)
메모리(주기억장치)는 **현재 실행되는 프로그램의 명령어와 데이터**를 저장합니다.
- 프로그램이 실행되려면 반드시 메모리에 저장되어야 합니다.
- 메모리에 저장된 값에 빠르고 효율적으로 접근하기 위해 **주소(Address)**라는 개념을 사용합니다.
- 대표적으로 **RAM(Random Access Memory)**과 **ROM(Read Only Memory)**이 있습니다.

### 캐시 메모리 (Cache Memory)
CPU와 주 메모리(RAM) 사이의 속도 차이를 줄이기 위해 사용하는 고속 메모리입니다.
- 메모리 접근 속도는 CPU 연산 속도보다 느리기 때문에, 자주 사용하는 데이터를 미리 캐시에 저장해 두어 성능을 향상시킵니다.
- **L1, L2, L3 캐시**: CPU에 가깝고 용량이 작을수록 빠릅니다.

## 2. CPU (Central Processing Unit)
CPU는 컴퓨터의 두뇌입니다. 메모리에 저장된 명령어를 읽어 들이고, 해석하고, 실행하는 부품입니다.

### CPU 내부 구성 요소
1. **ALU (Arithmetic Logic Unit)**: 산술(덧셈, 뺄셈 등) 및 논리 연산을 수행하는 계산 장치입니다.
2. **레지스터 (Register)**: CPU 내부의 작은 임시 저장 장치로, 처리 중인 데이터나 명령어를 저장합니다.
3. **제어 장치 (Control Unit)**: 제어 신호(Control Signal)를 내보내고 명령어를 해석하는 지휘자 역할을 합니다.

### 명령어 파이프라인 (Instruction Pipelining)
CPU의 성능을 높이기 위해 명령어 처리 과정을 여러 단계로 나누어 동시에 처리하는 기법입니다.
- 예: **인출(Fetch) -> 해석(Decode) -> 실행(Execute) -> 저장(Store)**
- 한 명령어가 실행 단계에 있을 때, 다음 명령어를 인출하는 식으로 병렬 처리하여 효율을 극대화합니다.

## 3. 보조기억장치 (Secondary Storage)
메모리(RAM)는 전원이 꺼지면 내용이 사라지는 **휘발성(Volatile)**을 가집니다. 이를 보완하기 위해 전원이 꺼져도 데이터를 영구적으로 저장할 수 있는 장치가 필요합니다.
- **종류**: HDD, SSD, USB 메모리, SD 카드 등
- 실행 중이지 않은 프로그램(코드)과 정적인 데이터(파일)를 보관합니다.

## 4. 입출력장치 (I/O Devices)
컴퓨터 외부에 연결되어 컴퓨터 내부와 정보를 교환하는 장치입니다.
- **입력 장치**: 마우스, 키보드, 마이크, 스캐너 등
- **출력 장치**: 모니터, 스피커, 프린터 등

# 메인 보드와 시스템 버스
이 모든 핵심 부품들은 **메인 보드(Motherboard)**라는 판에 연결됩니다. 메인 보드 내부는 **버스(Bus)**라는 통로로 연결되어 정보를 주고받습니다.

### 시스템 버스 (System Bus)
컴퓨터의 핵심 부품을 연결하는 가장 중요한 버스입니다.
1. **주소 버스 (Address Bus)**: 주소 정보를 주고받는 통로
2. **데이터 버스 (Data Bus)**: 명령어와 데이터를 주고받는 통로
3. **제어 버스 (Control Bus)**: 제어 신호를 주고받는 통로
